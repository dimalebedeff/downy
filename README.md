# Downy

Расширение Chrome для скачивания видео с любых сайтов: находит видео и аудио на страницах, а нативное companion-приложение (CoApp) скачивает и склеивает стримы через ffmpeg, для сложных сайтов используя yt-dlp.

## Что умеет

- Детект медиа на вкладке: прямые файлы (mp4, webm, mp3 и др.), HLS-стримы (m3u8) и DASH (mpd) — по сетевым запросам и по DOM.
- Попап со списком: превью-кадр, название, качество (варианты из мастер-плейлиста), размер/длительность. Если превью нет на странице, CoApp вытаскивает кадр через ffmpeg.
- Все загрузки идут через CoApp: HLS качается параллельным yt-dlp (быстро даже на троттлящих CDN вроде ВК), прямые файлы — сам CoApp. Единый список загрузок внизу попапа: очередь сверху (перетаскиванием меняется порядок), завершённые хвостом — со шкалой, скачанными МБ/ГБ, паузой, отменой и крестиком «убрать эту строку».
- Карточка видео не меняется никогда: «Скачать», выбор качества и меню «⋮» доступны и во время загрузки, и после неё. Скачал видео+звук — жмёшь ещё раз и берёшь отдельную дорожку, другое качество или отрезок.
- Кнопка «Скачать страницу через yt-dlp» — запасной экстрактор для сложных сайтов (YouTube и др.).
- Выбор дорожек: видео+звук, только видео или только звук — и для найденного медиа, и для yt-dlp.
- Самообновление: попап проверяет релизы на GitHub (раз в 6 часов) и предлагает кнопку «Обновить» — скачивание, пересборка и перезапуск расширения в один клик; заодно обновляется yt-dlp.
- DRM-контент (Netflix и т.п.) не поддерживается принципиально.

## Установка (Windows)

1. **Скачай проект**: на [странице релизов](https://github.com/dimalebedeff/downy/releases/latest) скачай архив **Source code (zip)** из раздела Assets и распакуй его в любое постоянное место, например на диск `D:`. Внутри окажется папка вида `downy-0.10.2` — это папка проекта, не удаляй её после установки: расширение и CoApp работают прямо из неё.
2. **Запусти `install.bat`** из папки проекта (двойной клик) и дождись надписи «Готово!». Скрипт сам всё сделает: если в системе нет Node.js — скачает портативный (без прав администратора), затем соберёт расширение, скачает ffmpeg/yt-dlp и зарегистрирует CoApp. Если Windows предупредит о неизвестном файле — «Подробнее» → «Выполнить в любом случае».
3. **Подключи расширение в Chrome**: набери в адресной строке `chrome://extensions`, включи справа сверху **«Режим разработчика»**, нажми **«Загрузить распакованное расширение»** и выбери папку `extension\dist` внутри папки проекта (она появляется после шага 2).
4. **Перезапусти браузер.**

Проверка: нажми на иконку Downy на странице с видео — точка-индикатор в шапке попапа загорится зелёным (по клику на неё — состояние помощника).

## Как пользоваться

1. Открой страницу с видео и запусти воспроизведение.
2. Нажми на иконку Downy: найденные видео покажутся карточками с превью, качеством и размером. Жми «Скачать» — кнопка мигнёт бликом, пока загрузка встаёт в очередь, а прогресс пойдёт в разделе «Загрузки» внизу попапа. «Только видео», «только звук» и «отрезок» — в меню «⋮». Карточка остаётся рабочей: можно тут же докачать вторую дорожку.
3. Если по сети ничего не поймалось, но на странице крутится видео (YouTube и т.п.) — покажется карточка страницы, качающая через yt-dlp. На совсем пустой вкладке — кнопка «Скачать страницу через yt-dlp».
4. Файлы сохраняются в `Downloads\downy`. Поменять папку: шестерёнка в шапке попапа → поле пути или кнопка «Обзор…». Там же галка «спрашивать каждый раз» — тогда перед каждой загрузкой откроется выбор папки.
5. Готовые файлы открываются прямо из списка: «▶» — открыть файл, «в папке» — показать в Проводнике, «✕» — убрать строку из списка (файл остаётся на диске).

## Если что-то пошло не так

Весь разбор — в одном файле `coapp\coapp.log` в папке проекта. Туда пишут и расширение, и нативный хост, поэтому цепочка читается по порядку: какой «Скачать» нажали `[popup]`, как загрузка встала в очередь `[bg]`, что принял хост и с каким кодом завершился yt-dlp. Прогресс и служебные пинги в лог не идут, чтобы он оставался читаемым; при старте хоста файл обрезается до последнего полумегабайта.

## Телеграм-бот (опционально)

Кидаешь боту ссылку в личку — он скачивает видео на этом ПК и присылает файл обратно в чат (до 2 GB, через MTProto), после отправки файл с диска удаляется. Модификаторы: `720` (качество), `audio` (только звук), `1:20-2:45` (отрезок). Если лучшее качество не влезает в лимит — пришлёт то, что влезает, и предложит кнопкой сохранить оригинал в `Downloads\downy`. Ссылки, присланные пока комп был выключен, скачаются при следующем включении.

Установка:

1. Возьми `apiId`/`apiHash` на [my.telegram.org](https://my.telegram.org) (API development tools) и токен бота у [@BotFather](https://t.me/BotFather).
2. `npm run bot:install` — создаст `bot/config.json`; заполни его и запусти команду ещё раз. Бот зарегистрируется в Планировщике задач (старт при входе в систему, перезапуск при падении).
3. Напиши боту что угодно — он ответит твоим chat_id; впиши его в `allowedChatIds` в конфиге и перезапусти задачу `DownyBot`. Бот приватный: всех, кого нет в списке, вежливо отшивает.

## Архитектура

```
extension/   MV3-расширение (TypeScript, esbuild)
  src/background.ts   сниффинг webRequest, m3u8-парсинг, связь с CoApp
  src/content.ts      детект <video>/<audio> в DOM
  src/popup/          UI списка и загрузок
coapp/       нативный хост (Node.js, Native Messaging)
  src/host.ts         задания: HLS через ffmpeg, прямые файлы, yt-dlp, кадры-превью
  install.mjs         регистрация native messaging host в реестре
  fetch-bins.mjs      загрузка ffmpeg/yt-dlp в coapp/bin
bot/         телеграм-бот (gramjs/MTProto): ссылка в чат — видео в ответ
  src/bot.ts          очередь, прогресс в чате, отправка до 2 GB, бэкфил пропущенного
  install.mjs         регистрация в Планировщике задач Windows
shared/      общий код
  protocol.ts         типы сообщений расширение ↔ CoApp
  ytdlp.ts            движок yt-dlp: разведка форматов и скачивание (CoApp и бот)
```

## Ограничения (пока)

- Только Windows и Chromium-браузеры (Chrome, Edge). Firefox — позже.
- Заголовки для ffmpeg передаются только Referer и User-Agent; куки не передаются — редкие сайты с куки-защитой сегментов не скачаются (обычно спасает yt-dlp).
